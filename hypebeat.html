HYPEBEAT 제작 기록 · v28

작곡할 때의 판단을
도구의 규칙으로 옮겼습니다

음악을 좋아하는 마음이 있어도, 만드는 법을 배울 기회는 모두에게 같지 않았습니다. AI가 제작의 문턱을 낮춘다면 제가 배운 것도 누군가의 시작을 도울 수 있지 않을까 생각했습니다. 그 질문을 제 작업에서 먼저 시험하며 HYPEBEAT를 만들었습니다. 기본은 도구가 채우되 직접 고른 것은 지키고, 작곡하면서 쌓은 기준을 반복해서 적용할 수 있도록 설계했습니다.

자동으로 채우되, 사람의 선택은 지킵니다

처음에는 모든 항목을 직접 채우게 만들었습니다. 쓰다 보니 매번 같은 값을 넣고 있었습니다.

  • 장르를 고르면 편성·포인트 악기·스타일이 자동으로 채워집니다
  • 이미 직접 고른 항목은 장르를 바꿔도 덮어쓰지 않습니다
  • 훅은 비워두면 AI가 만들고, 직접 쓰면 그대로 씁니다
  • 작사 원칙은 기본값이 들어 있고 수정할 수 있습니다

두 번째 항목이 핵심이었습니다. 자동이 편하려고 넣었는데, 사람이 고른 걸 지우면 더 불편해집니다. 장르를 바꿀 때마다 공들여 고른 설정이 날아가는 것을 겪고 나서 손댄 항목을 따로 추적하게 했습니다.

작곡가의 기준을 생성 규칙으로 바꿨습니다

장르를 섞어도 중심은 유지합니다

여러 장르를 같은 비중으로 섞으면 곡이 흔들립니다. 메인이 중심을 잡고 보조는 악센트로 쓰도록 했습니다.

참고할 것과 새로 만들 것을 구분합니다

참고곡에서는 악기·코드·템포·공간감 같은 질감만 가져옵니다. 참고 가사에서는 문장이 아니라 테마·정서·세계관을 가져옵니다. 표현을 그대로 옮기지 않도록 지시를 구성했습니다.

제 작업 원칙을 저장해 둡니다

작사 원칙과 믹싱 방향을 한 번 적어 두면 다음 작업에도 적용됩니다. 매번 설명하지 않아도 됩니다.

선택한 조건이 결과까지 이어지게 했습니다

장르를 골라도 화면 표시만 바뀌고 실제 결과물에는 반영되지 않던 때가 있었습니다. 직접 써 보며 발견해 고쳤습니다. 지금은 선택이 편곡 계획·가사·코드 진행·생성 지시문까지 함께 바뀝니다.

비용도 사용자가 판단할 수 있어야 했습니다

AI를 쓰면 돈이 듭니다. 얼마가 나갈지 모르고 누르는 것이 가장 불안했습니다.

  • 텍스트·오디오·이미지 모델을 각각 따로 고릅니다
  • 고를 때마다 「5달러로 몇 곡」을 즉시 다시 계산합니다
  • 스물네 개 조합의 곡당 비용을 전부 계산해 문서에 적었습니다
  • 계산 가정(환율·요청 횟수·분석 길이)과 제외한 비용도 함께 밝혔습니다
  • 같은 주소·같은 옵션·같은 모델은 저장해 두어 다시 분석하지 않습니다
다른 유료 모델로 몰래 바꾸지 않습니다
화면과 서버의 버전이 어긋나 허용되지 않은 모델명이 들어오면, 다른 유료 모델로 조용히 바꾸지 않고 오류로 막습니다. 고른 모델과 실제로 돈이 나가는 모델이 달라지는 일을 막기 위한 장치입니다.

지원이 끝난 모델은 선택지에서 빼고, 실제로 없는 모델은 만들지 않았습니다. 모델 가격은 공식 문서 주소를 함께 적어 확인할 수 있게 했습니다.

고치는 과정에서 돌아갈 길도 만들었습니다

새 버전이 더 나을 거라는 보장이 없었습니다. 그래서 되돌릴 수 있게 만들었습니다.

  • 설치할 때 파일이 빠져 있으면 중단합니다. 반쯤 설치된 상태를 만들지 않습니다
  • 새 버전은 임시 폴더에 먼저 받은 뒤 바꿔 넣습니다
  • 이전 버전은 버전명과 시각을 붙여 보관합니다
  • 마음에 들지 않으면 되돌립니다
  • 설정과 열쇠는 따로 둔 폴더에 보관하고 권한을 잠급니다

직접 쓰며 설계를 고쳤습니다

처음에는 제 작업을 빠르게 하려고 만들었습니다. 쓰다 보니 고른 값이 결과에 반영되지 않는 문제, 화면이 복잡해 어디를 눌러야 할지 모르겠는 문제가 보였습니다. 직접 쓰지 않았으면 몰랐을 것들입니다.

설치·실행·휴대폰 연결·복원 파일에 번호를 붙여 작업 순서를 드러냈습니다. 「2번 실행」이 두 번 클릭하라는 뜻으로 읽힐 수 있는 부분까지 설명에 보완했습니다.

혼자 쓰는 도구와 남이 쓸 수 있는 도구는 다른 물건이었습니다.

부록 — 실행 환경

번호언제 누르나
1 설치·업데이트처음 설치하거나 새 버전을 받았을 때 한 번
2 실행평소 맥에서 쓸 때. 주소와 여섯 자리 코드가 함께 뜸
3 휴대폰다른 통신망이나 LTE에서 열 때. QR이 나옴
4 이전 버전 복원새 버전이 마음에 들지 않을 때
5 고정 원격 주소직접 가진 도메인으로 고정 주소를 만들 때만

맥에서는 고정 주소로 열고, 같은 통신망의 휴대폰은 내부 주소, 다른 통신망이나 LTE는 임시 보안 주소와 QR로 엽니다. 휴대폰 주소창에 맥의 고정 주소를 치면 휴대폰 자기 자신을 가리켜 열리지 않습니다.
